Design a premium black and white luxury restaurant website for "Tehari Ghar".

Style direction:
Ultra minimal, high contrast, elegant typography, strong whitespace usage, cinematic food photography, luxury brand feel similar to Michelin-star restaurant websites.

Color palette:
Primary background: Pure Black (#000000)
Secondary background: Soft charcoal (#111111)
Text primary: White (#FFFFFF)
Text secondary: Light gray (#CCCCCC)
Accent: Subtle gold highlight (#C6A75E) used minimally for buttons and price badges.

Typography:
Heading font: High contrast serif (like Playfair Display / Cormorant / Cinzel)
Body font: Clean modern sans-serif (like Poppins / Inter)
Large hero typography with dramatic spacing.

UX Principles to apply:
- Hick’s Law (minimal navigation options)
- Fitts’s Law (large primary CTA buttons)
- Gestalt Principles (proximity, similarity, alignment)
- Visual hierarchy (clear size difference between headings and body)
- 8pt spacing system
- Clear CTA contrast
- Rule of thirds for hero layout
- Above-the-fold strong CTA
- Progressive disclosure (short text first, expandable details)
- Accessibility contrast ratio WCAG AA compliant

Layout structure:

1. Hero Section
- Full-screen background image (dark overlay 70%)
- Large centered heading: TEHARI GHAR
- Subtitle: Premium Traditional Tehari & Kacchi House in Dhaka
- Two CTA buttons:
   [ View Menu ] (white outline button)
   [ Order via WhatsApp ] (subtle gold solid button)
- Minimal top navigation (Menu, About, Branches, Contact)

2. About Section
- Split layout
- Left: Black & white portrait of owner
- Right: Elegant typography
- Minimal text
- Gold underline accent below name

3. Menu Section
- Grid layout (2 column desktop, 1 column mobile)
- Large food photography
- White cards on black background
- Floating price badge in gold
- CTA button with hover animation (micro interaction)

Menu items:
- Mutton Kacchi – 240 BDT
- Beef Kacchi – 210 BDT
- Jali Kabab – 60 BDT
- Tikka Kabab – 50 BDT

4. Branch Section
- Dark section with thin divider lines
- Left: Embedded map (dark mode)
- Right: Branch cards with subtle shadow
- “Get Direction” ghost button

5. Contact Section
- Full black background
- Clean input fields with white border
- Large green WhatsApp button
- Minimal form fields (Name, Phone, Message)

6. Footer
- Thin gold divider line
- Minimal text
- Social icons monochrome

Design characteristics:
- Use dramatic whitespace
- Remove unnecessary shadows
- Keep alignment perfect
- Consistent padding
- Smooth hover animations
- Subtle fade-in scroll animation
- Mobile-first responsive layout
- No clutter
- No bright colors except minimal gold accent

Goal:
Make the website feel like a high-end premium luxury traditional restaurant brand. Clean, confident, timeless, and conversion-focused.
